Selected work

Production system · System of record

Donor CRM & donation platform — Bala Chabad

Sole architect and engineer of the organization's first donor CRM — now the system of record for 550+ donors and 768+ gifts.

  • Security-first auth built from scratch: bcrypt, httpOnly-cookie JWT sessions, TOTP 2FA, invite-only registration, rate limiting, Helmet/CSP, HMAC-signed tokens.
  • Rule-based, fully explainable donor-analytics engine — lifetime value, giving cadence, lapse-risk scoring, and lifecycle segmentation, recomputed daily into an outreach dashboard.
  • Eliminated all manual donation entry with an email-to-database pipeline: payment-receipt email → Apps Script parser → serverless function → live site, with fuzzy donor matching and transaction-level dedup.
  • Deployed with Docker on Railway, GitHub Actions CI/CD, unit tests, and a pre-commit PII/secret guard.
