Production system · System of record

Donor CRM and donation platform for Bala Chabad

Sole architect and engineer of the organization's first donor CRM, now the operating record for 550+ donors and 768+ gifts.

  • Security-first auth: bcrypt, httpOnly-cookie JWT sessions, TOTP 2FA, invite-only registration, rate limiting, Helmet/CSP, and HMAC-signed tokens.
  • Explainable donor analytics: lifetime value, giving cadence, lapse-risk scoring, and lifecycle segmentation recomputed into an outreach dashboard.
  • Donation automation: receipt email to Apps Script parser to serverless function to live database, with fuzzy donor matching and transaction-level deduplication.
  • Run like production: Docker, Railway, GitHub Actions CI/CD, tests, backups, and a PII/secret guard.

Runtime-injection loader for a locked-down CMS

The public website lived inside a third-party CMS with no backend access. I used the one available site-wide header field to ship a compact URL-routing loader that injects page-specific JavaScript apps hosted on Netlify.
