Private production system · System of record

Donor CRM and donation tools for Bala Chabad

Built and operate a production CRM and donation-processing system, replacing fragmented manual tracking with secure donor records, outreach context, automated receipt ingestion, reporting, backups, and CI/CD.

  • Security-first auth: bcrypt, httpOnly-cookie JWT sessions, TOTP 2FA, invite-only registration, rate limiting, Helmet/CSP, and HMAC-signed tokens.
  • Donor context: 550+ donor profiles with giving history, cadence, notes, campaign participation, and lifecycle views for outreach.
  • Donation automation: receipt email to parser to serverless function to database, with fuzzy donor matching and transaction-level deduplication across 768+ gifts.
  • Production habits: Docker, Railway, GitHub Actions CI/CD, tests, backups, and a PII/secret guard.

Automation and constraint engineering

Runtime-injection loader for a locked-down CMS

Designed a runtime JavaScript loader that turned a locked-down third-party CMS into a deploy target for page-specific apps. With only a site-wide header field available, the loader routes pages to Netlify-hosted modules.

  • Powers custom donation pages, a capital-campaign experience, and a live donor-recognition wall.
  • Supported a year-end campaign page with live progress, cost-category cards, donor recognition, and cleaner donation flows.
  • Let nontechnical staff keep using the CMS while custom apps shipped independently through git-based deploys.
